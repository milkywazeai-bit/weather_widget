# 날씨 예보 비교 위젯 (Android)

여러 기관의 수치예보 모델을 홈 화면 위젯 하나에서 나란히 비교하는 안드로이드 앱입니다.
같은 날 같은 장소에 대해 기상청, ECMWF, GFS 등이 각각 어떻게 예보하는지 보고,
모델들이 얼마나 일치하는지(= 예보의 신뢰도)를 바로 확인할 수 있습니다.

```
┌──────────────────────────────────────────────┐
│ 서울                          [오늘 ▸]   ↻   │
│ 10/13 (화) · 14:05 업데이트                  │
│ 모델   날씨  현재   최고/최저        강수    │
│ KMA    🌤️    18°   22° / 12°         0㎜    │
│ ECMWF  ⛅    19°   23° / 13°       0.2㎜    │
│ GFS    ☁️    20°   25°▲ / 13°   10% 0.2㎜    │
│ ICON   🌤️    18°   22° / 11°▼        0㎜    │
│ JMA    ⛅    19°   23° / 12°         0㎜    │
│ ──────────────────────────────────────────── │
│ 평균 23° / 12° · 최고기온 편차 3° · 비 예보 0/5 │
└──────────────────────────────────────────────┘
```

## 기능

- **모델별 비교**: 날씨 아이콘, 현재 기온, 최고/최저 기온, 강수확률·강수량을 모델마다 한 줄씩 표시
  - ▲ / ▼: 모델들 중 가장 높은 최고기온 / 가장 낮은 최저기온
- **합의(컨센서스) 요약**: 평균 최고/최저, 모델 간 최고기온 편차, 1㎜ 이상 비를 예보한 모델 수
- **오늘 / 내일 / 모레** 전환: 위젯의 날짜 버튼을 탭
- **↻** 버튼으로 즉시 새로고침, 그 외에는 1시간마다 자동 갱신 (WorkManager)
- 위젯 본문을 탭하면 설정 화면이 열립니다
  - 도시 검색 또는 현재 위치(대략적 위치 권한) 사용
  - 비교할 모델 선택
- 라이트/다크 모드 대응, 크기 조절 가능 (기본 4×3)

## 비교 가능한 모델

| 표시 | 기관 | 기본 선택 |
|---|---|---|
| KMA | 기상청 (한국) | ✅ |
| ECMWF | 유럽중기예보센터 (IFS 0.25°) | ✅ |
| GFS | NOAA (미국) | ✅ |
| ICON | DWD (독일) | ✅ |
| JMA | 일본 기상청 | ✅ |
| UKMO | Met Office (영국) | |
| MF | Météo-France | |
| GEM | 캐나다 기상청 | |

데이터는 [Open-Meteo](https://open-meteo.com/) 의 무료 API(키 불필요)에서 한 번의 요청으로
모든 모델을 함께 가져옵니다. 모델에 따라 강수확률 등 일부 값이 제공되지 않으면 `–` 로 표시됩니다.
Open-Meteo 무료 API는 비상업적 용도로 제공되며 데이터 라이선스는 CC BY 4.0 입니다.

## 빌드

Android Studio(최신 버전)에서 프로젝트 폴더를 열고 실행하거나:

```bash
./gradlew assembleDebug        # app/build/outputs/apk/debug/app-debug.apk
./gradlew testDebugUnitTest    # 파서/컨센서스 단위 테스트
```

- minSdk 26 (Android 8.0), targetSdk 35
- Kotlin, RemoteViews 기반 위젯, WorkManager

설치 후 홈 화면을 길게 눌러 **위젯 → 날씨 예보 비교** 를 추가하세요.

## 구조

| 파일 | 역할 |
|---|---|
| `WeatherModel.kt` | 비교 대상 모델 목록 (Open-Meteo 모델 ID) |
| `OpenMeteoClient.kt` | 예보·지오코딩 API 호출 |
| `OpenMeteoParser.kt` | 다중 모델 응답(`변수_모델ID`) 파싱 |
| `Forecast.kt` | 데이터 클래스, 모델 간 합의(Consensus) 계산 |
| `RefreshWorker.kt` | 주기/즉시 갱신, 응답 캐시 |
| `CompareWidgetProvider.kt` | 위젯 이벤트(새로고침, 날짜 전환) 처리 |
| `WidgetRenderer.kt` | 캐시된 예보로 위젯 RemoteViews 구성 |
| `SettingsActivity.kt` | 위치·모델 설정 (위젯 구성 화면 겸용) |
